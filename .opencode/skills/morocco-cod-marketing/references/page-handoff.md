# Product-page handoff brief

The user transfers a finished strategy to their design skill
(`product-page-marketing-sections`) by giving it the path of this product's
Obsidian note. The brief saved there as `## Product-page brief` lets the
design skill implement marketing sections without re-asking marketing
questions.

## Brief contents

- Target: product name and note path.
- Naming: the approved French marketing name, kept distinct from the factual
  catalog identity so the design skill does not accidentally rename catalog
  data.
- Strategy: approved audience, situation, angle and promise, in English
  (the design skill reads the note, so the brief is written for it).
- Customer questions: the 1–3 buying hesitations the sections must answer,
  in priority order, tied to the approved direction.
- Message per question: outcome → reason → evidence, using only confirmed
  facts, recorded quotes or factual demonstrations.
- Suggested customer-facing copy in the approved language (French by
  default): headlines and short supporting lines, labelled as
  suggestions the design skill may adapt.
- Evidence available: authenticated quotes with sources, demonstrations
  the design skill can depict truthfully, and real policies. State
  explicitly what does not exist — e.g. no reviews yet, so the design
  skill should use a factual demonstration section instead.
- Commerce facts: confirmed price, delivery terms, COD payment
  ("paiement à la livraison"), confirmation call and return policy —
  only what the user confirmed.
- CTA guidance: link to the existing order form; never invent discounts,
  deadlines, review counts or guarantees.
- Language: the approved customer-facing language.

## Product-gallery prompts

Include exactly four paste-ready image-generation prompts in English. Each
prompt must specify the product placement and position, framing or camera
angle, environment/background, lighting, composition and suitable product-
gallery aspect ratio. Give the four images complementary jobs:

1. Clean hero composition that presents the whole product clearly.
2. Realistic in-use scene that demonstrates the approved main benefit.
3. Close-up composition that truthfully highlights one confirmed feature.
4. Aspirational lifestyle composition grounded in the approved audience and
   transformation.

Keep the real product's shape, colors, materials, proportions, logo and
visible details consistent with the supplied assets. Do not invent features,
accessories, variants, claims or packaging. Avoid text inside gallery images
unless the user explicitly requests it; customer-facing copy remains in the
page brief. The prompts should show attractive, meaningfully different
positions rather than four cosmetic variations of one scene.

## Division of labor

This skill owns message and evidence; the design skill owns layout, visual
direction and section selection (it normally picks 1–3 sections and adapts
to the store). Do not prescribe exact layouts; do provide message, proof
and CTA so the design skill never has to invent marketing substance.

The brief must repeat the ad package's core promise so the click lands on
a consistent page: same audience, same angle, same benefit language, same
CTA destination. If the strategy changes later, mark the brief
`needs-review` along with the ads.
