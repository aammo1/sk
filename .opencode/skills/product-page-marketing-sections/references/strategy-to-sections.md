# Turn a strategy into a useful addition

## Selection principles

Read the existing page before adding copy. Identify the gap between what the customer currently knows and what the supplied strategy needs them to understand. A section earns its place by closing that gap.

For each proposed section, define:
1. **Customer question:** what hesitation or desire it addresses.
2. **Message:** one useful takeaway aligned with the user's strategy.
3. **Evidence:** actual product fact, image, demonstration, policy, or customer experience.
4. **Composition:** a beautiful, polished layout serving this product, brand, and strategy; optionally adapt or mix library recipes, or invent a new coherent direction.
5. **Next step:** continue reading or use the existing buying controls.

Do not add hero, offer, FAQ, and reviews automatically when the page already provides them. The requested output is an addition, not a replacement page.

## Strategy mapping

These mappings and section sequences are optional starting points, not required templates. Choose the smallest useful set and adapt the layout and order to the strategy.

| Strategy / customer question | Good section choices | Evidence needed |
|---|---|---|
| Recognize an everyday frustration | Problem gallery → reassurance/solution demonstration | Relevant situations and factual capabilities |
| Explain an unfamiliar solution | Mechanism/cutaway → illustrated steps | Accurate mechanism and instructions |
| Emphasize convenience or low effort | Demonstration → 3-step guide → maintenance detail | Actual steps, controls, maintenance |
| Show visual change | Labeled comparison or progression | Genuine comparable results and context |
| Establish quality | Macro detail gallery or annotated construction | Actual materials and close-ups |
| Establish relevance to several situations | Use-case gallery | Genuine supported uses |
| Address fit or compatibility | Compatibility diagram/grid | Exact supported models, sizes, connections |
| Emphasize portability | In-hand/bag scale composition | Dimensions/weight and suitable imagery |
| Justify value or savings | Alternative-cost explanation; optional genuine bundle | Real costs, assumptions, current offer |
| Build transaction confidence | Relevant reviews + compact policy strip/FAQ | Authentic reviews and current policies |
| Communicate enjoyment or aspiration | Lifestyle outcome + feature-to-benefit explanation | Realistic scene and supporting capability |
| Emphasize materials/ingredients | Component spotlight + role explanation | Actual composition, supportable properties |

## Number and placement

- **One section:** one headline, one persuasive visual, 2–3 supporting facts, optional CTA to the existing form.
- **Two sections:** benefit/demonstration first; evidence/reassurance second.
- **Three sections:** recognize the situation; explain/demonstrate; resolve hesitation.
- **More:** only when distinct unresolved questions or explicit user instructions justify them.

Prefer placement below the current product summary and purchase controls unless another location better matches the user's request. Insert within the informational content, outside forms and interactive galleries. Preserve existing content order unless moving a new section itself.

Repeat CTAs at meaningful decision points, not after every card. A compact addition often needs one CTA or none if the purchase controls are already adjacent.

## Copy and proof

Use outcome → reason → evidence:
> “[Useful outcome]. [Specific feature] makes [task] easier. [Image or fact demonstrating it].”

Use headings that communicate meaning without the body copy. Prefer concrete customer language over repeated “premium,” “revolutionary,” or “best.” Keep mobile paragraphs short, typically 1–3 sentences.

Distinguish:
- A **feature** is a property.
- A **benefit** is why that property matters.
- A **demonstration** shows a task or mechanism.
- **Proof** substantiates a claim.
- A **decorative illustration** establishes atmosphere but does not prove a result.

Avoid generic testimonials, inconsistent discount arithmetic, unsupported percentages, and stock authority cues. A reusable section structure supplies no product facts. Use actual current store policies instead of template promises.

For savings, show the calculation and assumptions. For a discount, compute `(reference − current) / reference × 100`; use a legitimate reference price. Avoid time-limited language without an actual promotion deadline. For genuine before/after results, label context and time period where known; do not manufacture results by editing images.

If the supplied strategy asks for reviews but none are available, explain briefly and use a factual detail/demo section where appropriate. If authentic reviews are an essential explicit requirement, request them rather than fabricate them. Missing secondary proof should not block other supported sections.

## Examples

### Convenience strategy, existing order form
Input: “Add sections showing that it is easy to use while travelling. Use large mobile photos and short numbered instructions.”
Choice: in-hand or bag photograph with dimensions, then three illustrated usage steps. Place after the purchase summary. Add one link back to the existing order form if useful. Reuse actual images and instructions; no new purchase state.

### Quality strategy, no testimonials
Input: “Convince customers this is durable; add trust.”
Choice: annotated construction image + care/support strip using confirmed materials and policies. Do not invent reviews or a warranty. Two sections can be enough.

### Value strategy, no pricing change requested
Input: “Show how it reduces repeated costs. Keep checkout intact.”
Choice: explain the recurring alternative using known costs and clearly stated assumptions, or a qualitative convenience comparison when costs are unavailable. Link to the existing options. Do not edit catalog prices or introduce a discount.

### Specific visual direction
Input: “Use bold heading bands and alternating numbered photo/text panels; strategy is easy setup and easy maintenance.”
Choice: use numbered alternating photo/text steps and an accurate disassembly/cleaning illustration if assets support it. Preserve the checkerboard narrative and clear heading bands while using the current brand palette and actual product imagery.
